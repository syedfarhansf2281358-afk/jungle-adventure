# 🌴 Jungle Ruins — 3D मल्टीप्लेयर जंगल एडवेंचर (प्रोटोटाइप)

2–4 दोस्त ब्राउज़र में एक साथ जंगल घूमें, पुराने रुइन्स में जाएँ और मिशन पूरे करें।
थर्ड-पर्सन कैरेक्टर (चलना, दौड़ना, कूदना), घना जंगल, वाइन्स, पत्थर के रुइन्स और प्राकृतिक रोशनी।

**इसमें `npm install` की ज़रूरत नहीं है।** सर्वर में कोई बाहरी पैकेज नहीं है, और Three.js ब्राउज़र खुद CDN से लोड करता है।

---

## 1. ज़रूरी चीज़ें

| चीज़ | कितना नया |
|---|---|
| Node.js | **20 या उससे नया** (https://nodejs.org से LTS डाउनलोड करो; `node -v` से जाँचो) |
| ब्राउज़र | Chrome / Edge / Firefox का नया वर्शन (WebGL चालू) |
| इंटरनेट | पहली बार Three.js CDN से लोड होने के लिए |
| कंप्यूटर | कोई भी ठीक-ठाक लैपटॉप। कमज़ोर GPU हो तो `?quality=low` इस्तेमाल करो |

## 2. चलाने के स्टेप

```bash
cd jungle-adventure
npm start
```

टर्मिनल में ऐसा कुछ दिखेगा:

```
🌴 Jungle Ruins server चालू है
   इसी कंप्यूटर पर:   http://localhost:3000
   उसी WiFi पर दोस्त: http://192.168.1.23:3000
```

1. ब्राउज़र में **http://localhost:3000** खोलो।
2. नाम लिखो और **"नया रूम बनाओ"** दबाओ। ऊपर बाईं तरफ 4 अक्षर का **रूम कोड** दिखेगा।
3. दोस्त वही पेज खोलकर कोड डालें और **"जुड़ो"** दबाएँ। या **🔗 लिंक** बटन से जॉइन-लिंक कॉपी करके भेज दो।
4. गेम पर क्लिक करो ताकि माउस कैमरे से जुड़ जाए (`Esc` से छूटेगा)।

अकेले टेस्ट करना हो तो एक ही कंप्यूटर पर दो ब्राउज़र टैब खोलकर एक में रूम बनाओ और दूसरे में जुड़ो।

### कंट्रोल्स

| की | काम |
|---|---|
| `W A S D` / तीर | चलना |
| `Shift` | दौड़ना |
| `Space` | कूदना |
| माउस | कैमरा घुमाना (क्लिक करके पकड़ो, या बटन दबाकर घसीटो) |
| `Q` / `E` | कैमरा बाएँ / दाएँ घुमाना |
| स्क्रॉल | ज़ूम इन / आउट |

### मिशन (प्रोटोटाइप में 2)

1. **प्राचीन अवशेष**: हर रुइन्स की वेदी पर चमकता क्रिस्टल है। उसके पास जाओ तो उठ जाता है।
2. **रुइन्स की खोज**: सभी 5 रुइन्स के अंदर कदम रखो।

मिशन पूरे रूम के साझा होते हैं। कोई भी दोस्त अवशेष उठाए तो सबके HUD में प्रोग्रेस बढ़ती है।

## 3. दोस्तों के साथ ऑनलाइन खेलना

**एक ही WiFi पर:** दोस्त टर्मिनल में दिखा `http://192.168.x.x:3000` वाला पता खोलें। अगर न खुले तो अपने कंप्यूटर का फ़ायरवॉल Node.js को इजाज़त दे।

**इंटरनेट पर (अलग-अलग शहर):** सबसे आसान तरीका एक टनल है। नया टर्मिनल खोलकर चलाओ:

```bash
# विकल्प A: Cloudflare (मुफ़्त, अकाउंट नहीं चाहिए)
cloudflared tunnel --url http://localhost:3000

# विकल्प B: ngrok
ngrok http 3000
```

जो `https://....` पता मिले वह दोस्तों को भेज दो। गेम अपने-आप `wss://` इस्तेमाल करता है।
स्थायी रूप से होस्ट करना हो तो इसे किसी भी Node.js होस्ट (Render, Railway, Fly.io, VPS) पर `npm start` से चला सकते हो। पोर्ट `PORT` एनवायरनमेंट वेरिएबल से तय होता है।

## 4. सेटिंग्स और ट्रबलशूटिंग

| समस्या | हल |
|---|---|
| `Port 3000 पहले से इस्तेमाल में है` | `PORT=3001 npm start` (Windows PowerShell: `$env:PORT=3001; npm start`) |
| गेम धीमा / अटक रहा है | `http://localhost:3000/?quality=low` (कम पेड़, बिना परछाईं) |
| काली स्क्रीन / WebGL त्रुटि | ब्राउज़र में हार्डवेयर एक्सेलेरेशन चालू करो, ब्राउज़र अपडेट करो |
| Three.js लोड नहीं हो रहा | इंटरनेट जाँचो। पूरी तरह ऑफ़लाइन चलाना हो तो एक बार `npm install three` चला दो। सर्वर `node_modules/three` मिलने पर उसे अपने-आप इस्तेमाल करता है |
| "ऐसा कोई रूम नहीं मिला" | कोड 4 अक्षर का है, बड़े/छोटे अक्षर से फ़र्क नहीं पड़ता। सर्वर रीस्टार्ट होने पर सारे रूम मिट जाते हैं |
| दोस्त जुड़ नहीं पा रहा | अलग नेटवर्क पर हो तो ऊपर बताई टनल इस्तेमाल करो |

टेस्ट चलाने के लिए: `npm test` (वर्ल्ड, फ़िज़िक्स, सर्वर और मल्टीप्लेयर के 24 चेक)।

## 5. प्रोजेक्ट का ढांचा

```
jungle-adventure/
├─ server/
│  ├─ index.js      HTTP + WebSocket सर्वर, रूम में जुड़ने की लॉजिक, फ़्लड-प्रोटेक्शन
│  ├─ rooms.js      Room / RoomManager: खिलाड़ी, कोड, 15 Hz स्नैपशॉट
│  ├─ missions.js   मिशन की प्रोग्रेस, सर्वर पर जाँची जाती है (चीटिंग से बचाव)
│  └─ ws.js         बिना लाइब्रेरी का छोटा WebSocket (RFC 6455)
├─ shared/          सर्वर और ब्राउज़र दोनों यही फ़ाइलें चलाते हैं
│  ├─ worldgen.js   seed से पूरा जंगल: ज़मीन, पेड़, रुइन्स, वाइन्स, कोलाइडर
│  └─ missions.js   मिशन की परिभाषाएँ
├─ public/
│  ├─ index.html, style.css
│  └─ js/
│     ├─ main.js      लॉबी → गेम लूप → नेटवर्क
│     ├─ world.js     जंगल के 3D मॉडल (instanced पेड़, फ़र्न, रुइन्स, वाइन्स, अवशेष)
│     ├─ lighting.js  आसमान, सूरज, परछाईं, धुंध
│     ├─ textures.js  सारी टेक्सचर कोड से बनती हैं (कोई इमेज फ़ाइल नहीं)
│     ├─ avatar.js    खिलाड़ी का कैरेक्टर और चलने का एनिमेशन
│     ├─ physics.js   चलना / दौड़ना / कूदना / टकराव
│     ├─ controls.js  कीबोर्ड, माउस, ऑर्बिट कैमरा
│     ├─ net.js       WebSocket क्लाइंट
│     ├─ effects.js   जुगनू
│     └─ ui.js        लॉबी और HUD
└─ test/smoke.js
```

### मल्टीप्लेयर कैसे काम करता है

- सर्वर रूम बनाते समय एक **seed** चुनता है और सिर्फ़ वही सबको भेजता है। हर क्लाइंट `shared/worldgen.js` से **एक जैसा जंगल** खुद बना लेता है, इसलिए नेटवर्क पर मैप नहीं जाता।
- हर क्लाइंट सेकंड में 15 बार अपनी पोज़िशन भेजता है। सर्वर सबकी पोज़िशन का स्नैपशॉट वापस बाँटता है। बाकी खिलाड़ियों को स्मूद इंटरपोलेशन से दिखाया जाता है।
- मिशन **सर्वर तय करता है**: क्लाइंट सिर्फ़ "मैंने अवशेष उठाया" कहता है, और सर्वर जाँचता है कि खिलाड़ी सचमुच पास था या नहीं।

## 6. आगे क्या जोड़ें (आर्किटेक्चर इसी के लिए बना है)

| सुविधा | कहाँ जोड़ें |
|---|---|
| **नया मिशन** | `shared/missions.js` में एंट्री जोड़ो। फिर `server/missions.js` के `validate()` में उसकी जाँच। HUD अपने-आप दिखाएगा |
| **दुश्मन (जानवर/गार्ड)** | `server/enemies.js` बनाओ, `Room` में एक `tick()` से चलाओ, पोज़िशन `snap` संदेश में जोड़ो, और क्लाइंट पर `Avatar` जैसा एक `EnemyView` बनाओ |
| **आइटम / इन्वेंट्री** | `world.relics` जैसी ही एक `items` सूची `worldgen.js` में, `collect` जैसा संदेश, और `ui.js` में इन्वेंट्री पैनल |
| **बड़ा मैप** | `WORLD_SIZE` बढ़ाओ और `world.js` में ज़मीन को चंक्स में बाँटो। पेड़ों के लिए LOD जोड़ो |
| **असली फ़ोटो-रियलिस्टिक ग्राफ़िक्स** | `textures.js` की जगह PBR टेक्सचर सेट (ambientCG, Poly Haven पर मुफ़्त), `world.js` के पेड़ों की जगह GLTF मॉडल, `avatar.js` में स्किन्ड कैरेक्टर (Mixamo)। HDRI आसमान और पोस्ट-प्रोसेसिंग (SSAO, bloom) जोड़ने से लुक बहुत बदलेगा |
| **वॉइस / चैट** | `chat` संदेश का टाइप जोड़ो, या WebRTC |

## 7. प्रोटोटाइप की सीमाएँ (सच्ची बात)

- **ग्राफ़िक्स "फ़ोटो जैसे" नहीं हैं।** यह ब्राउज़र में चलने वाला स्टाइलाइज़्ड-रियलिस्टिक जंगल है (असली लाइटिंग, परछाईं, धुंध, घना जंगल)। असली फ़ोटो-रियलिज़्म के लिए बाहरी आर्ट एसेट चाहिए (ऊपर सेक्शन 6)। Unreal Engine जैसे इंजन में यह स्तर ज़्यादा आसानी से मिलता है, पर वहाँ सेटअप भारी है।
- खिलाड़ी की चाल क्लाइंट तय करता है (सर्वर सिर्फ़ सीमा-जाँच करता है)। दोस्तों के बीच खेलने के लिए यह ठीक है, पर प्रतियोगी गेम के लिए सर्वर-ऑथोरिटेटिव फ़िज़िक्स चाहिए होगी।
- कोई सेव/लॉगिन नहीं है। सर्वर बंद होते ही रूम मिट जाते हैं।
